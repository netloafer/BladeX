# Task Ledger Template

<!-- BladeX Ledger template (V-L6, ADR-0032 §4.1).
     This file is USER-EDITABLE: the "## Section" list below defines the
     structure of every NEW ledger, and the section descriptions are shown to
     the model when it opens a ledger. Add a section (e.g. "## Lessons") and
     new ledgers will carry it. The Goal section cannot be removed. -->

## Goal

_(Set from the user's own words when the ledger is created — the end goal,
hard constraints, acceptance criteria. Only the user may change it.)_

## Core

_(Key facts that must stay true for the whole task: architecture points,
confirmed decisions, user's explicit taboos, key file paths. NOT a to-do list —
steps belong in Next. When the ledger is created this holds what the USER
already told you; anything else goes in only once VERIFIED — a wrong "constant"
here gets repeated every turn.)_

## Verified

_(Only evidence-backed results: tool outputs, passing tests, user confirmations.
Each entry should carry its source.)_

## Open

_(Unresolved questions, unconfirmed assumptions, risks, conflicts —
check here before making decisions.)_

## Next

_(1-5 concrete, prioritized, executable actions — PENDING only. When an action
completes, REMOVE it and record the outcome in Verified (or Open); never keep
completion records here.)_
